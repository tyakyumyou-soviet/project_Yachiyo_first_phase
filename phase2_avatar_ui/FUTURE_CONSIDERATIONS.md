# 将来の検討事項 (Phase 2)

## 高度なリップシンクと表情制御（B法）への移行
現在は安定稼働を優先し、音声ファイルの波形（音量）を用いたブラウザ内でのリップシンク（A法）を採用している。

しかし、よりリアルなVTuber水準のアニメーションを実現するためには、LLMの思考やタグから抽出した「感情データ」と、TTSエンジンが出力する「母音（音素）」のタイミングを結合し、ミリ秒単位の同期ストリームとしてWebSocket経由でフロントエンドに流し込む「精密同期方式（B法）」への改修が必要不可欠となる。

そのため、フロントエンド（React/Three-vrm側）の初期コード設計段階から、こうしたWebSocketストリームの割り込みを受け入れ可能なステート（状態フック）構造をあらかじめ構築しておく方針である。
